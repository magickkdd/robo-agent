## 4. RQ9（E1'）：L2 的率定不下来（这是答案）；L6 跨席无可分之差

**批止于 34/60 集**（agnes 免费档配额两窗口各 8 连 429；故障切换席 sensenova 第一真实块
即健康——12 集零死亡——但切换席按预登记字面只用一次）。实际 700/2,340 请求。

| 读数 | 模型席（34 集） | rule 席（60 集） |
|---|---|---|
| **L2.dependency_edge_violation** | **触发率 1/34**（run 1 的 1 个触发；run 2/3 零触发） | 结构性 0/0（rule 从不写依赖边，与 v0.3 一致） |
| **L6.replanning_effectiveness** | **0.5（10/20）**（agnes 6/11 与 3/5、sensenova 1/4） | **0.5（10/20）**（60 个不同场景；repeat 变种子已验证） |
| L6.recovery_effectiveness | —（对照行） | 1.0（20/20） |
| L1.assignment_completion | 每块 0.68 / 0.67 / 0.79 | 0.8（240/300） |

- **L2 的答案**：触发率实测 1/34——**D5' 的 2/12 估计被大样本修正，两位数触发在任何
  可负担规模上都不可达**（60 集也只给 ~2 个）。交付的是触发率与区间，不是率。
  "模型什么时候写依赖边"本身成了新的研究问题（写边行为稀有且突发：3 个 run 里 1 个有）。
- **L6 的答案**：**跨席 0.5 vs 0.5，无可分之差**——v0.3 的"0.5789 vs 0.0"对比里 rule 侧的
  0/4 是 v0.2 时代读数（其 LH-2 产物在 /tmp 已灭失，无法回产物核对；v0.2 的 mode-B 决策环
  与今日 RulePlanner 本就不是同一实现，差异未决、如实记录）。今日同仪器同冻结集的
  新鲜对照：两个席的重规划有效性都是抛硬币水平，且**在 20 轮的分母上仍然不可分**。
  §17 的那句"它们能被测到这件事本身是进步，但方向与大小都还不能作为结论用"——
  L6 的"方向"现在有了答案：**没有方向**。
- **顺带的干净负结果**：c6（双扰动）在**全部三个决策源上全灭**——rule 席 10/10
  INVALID_DECISION 确定性失败、模型席 6/6 失败（两席皆是）。c6 也是重复颜色 case，
  但它在这几格的失败与颜色无关（rule/特权态不走接地图），不得读成 R3 的读数。

## 6. 负结果清单（v0.4）

1. **full-on-VLM 0/4（匹配分母）**——干净负结果（§3）；感知接口是瓶颈。
2. **L2 触发率 1/34**——D5' 的规模目标（两位数触发）被实测证伪；两位数需要 ~680 集。
3. **L6 跨席 0.5 vs 0.5**——重规划有效性在两个决策源上都是抛硬币水平，20 轮分母不可分。
4. **c6 三决策源全灭**（rule 10/10 确定性、模型席 6/6）——双扰动任务结构超出全部现有
   决策器；与接地无关。
5. **E1' 止于 34/60**——免费档配额是结构性约束；差值表见 §7。
6. **sensenova 的资格是"尺寸合格"而非"真实决策轮合格"**——合成载荷内容简单，真实健康度
   只有它的一个块（12 集零死亡）作证。
7. **v0.2 时代 rule L6 0/4 与今日 0.5 (10/20) 的差异未决**——其产物在 /tmp 已灭失。
8. **E1' 驱动的 batch_spend 目录深度 bug**——上界守卫全程未武装（配额规则独立生效才是
   实际停止者）；已修，账目事后重导。
9. **v0.3 报告 §18 的两条残留前提不成立 + 一处倒置**（P1 重判；已更正于其 §19）。
10. **v0.1 门槛组 G5 未达标等 v0.3 之前的负结果**——按 SPEC §12.9 的字面继续携带，不翻身也不删除。
